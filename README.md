# F1TENTH Autonomous Racing

An appearance-preserving copy of the original ECE 484 final project website. Original team credits are retained; the team identifier has been removed.

## Publish with GitHub Pages

1. Create a public repository named `f1tenth-autonomous-racing` in your GitHub account.
2. Upload the contents of this folder, including `index.html`, `styles.css`, `search.json`, `site_libs`, `static`, and `.nojekyll`, to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/ (root)** and save.
4. GitHub will display the published URL on that page when deployment completes.

The URL will be `https://YOUR-USERNAME.github.io/f1tenth-autonomous-racing/`. For a URL with no repository suffix, use a repository named `YOUR-USERNAME.github.io`.

## Preview locally

Run `python3 -m http.server 8000` from this folder, then open http://localhost:8000.

Edit `index.html` for content and `styles.css` for custom styling. The original published HTML and all linked assets were preserved rather than regenerated, because the original Quarto source repository was unavailable.
